# 微信云托管（CloudBase Run）部署指南

> 目标：把「影境档案」的 FastAPI 后端搬到微信云托管，**免自购服务器、免 ICP 备案**，
> 并可配合微信小程序使用。

## 一、为什么选云托管

- 跑 Docker 容器，现有 FastAPI + LangChain 代码基本不动
- 腾讯云提供合规访问域名，**无需自行 ICP 备案**
- 小程序可直接调用（云调用 / request 合法域名）

## 二、前置准备

1. **微信小程序 AppID**：已注册的小程序（企业主体，认证约 300 元/年）
2. **腾讯云账号**：实名认证
3. **一个 OpenAI 兼容的大模型 Key**（DeepSeek / 通义 / 智谱等，用于 AI 推荐与解读）

## 三、部署步骤

### 第 1 步：开通云开发 / 云托管

1. 微信公众平台 → 登录小程序 → 「开发」→「云开发」开通
2. 进入云开发控制台，找到「**云托管**」（CloudBase Run）
3. 创建环境（按量计费即可）

### 第 2 步：准备 MySQL 数据库

云托管容器是临时的，**不能用 SQLite 文件**（重启即丢），要换成 MySQL：

1. 云开发控制台 → 「数据库」→ 开通 **MySQL 数据库**（云开发 MySQL / TDSQL-C）
2. 创建一个数据库，记下：**内网地址、端口、用户名、密码、库名**

### 第 3 步：上传代码 / 构建镜像

**方式 A（推荐，控制台直接构建）**：云托管 → 新建服务 → 上传代码包（本仓库 `backend/` 目录，已含 `Dockerfile`）→ 云端自动构建镜像。

**方式 B（本地构建后推送）**：

```bash
cd cinelib/backend
docker build -t cinearchive .
# 推送到腾讯云容器镜像服务 TCR，再在云托管里选该镜像
```

### 第 4 步：配置环境变量

在云托管服务的「环境变量」里填：

```dotenv
# 数据库（换成你自己的 MySQL 连接信息）
CINELIB_DATABASE_URL=mysql+pymysql://用户名:密码@mysql内网地址:3306/库名?charset=utf8mb4

# 大模型（OpenAI 兼容）
LLM_API_KEY=你的key
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat

# 微信登录
WX_APPID=wx你的appid
WX_APP_SECRET=你的secret

# JWT 密钥（务必改成随机长字符串）
JWT_SECRET=换成随机长字符串

# 公众号 H5 网页授权回调（走 H5 才需要，小程序可留空）
# MP_OAUTH_REDIRECT_URI=https://你的云托管域名/api/v1/auth/mp/callback
```

### 第 5 步：部署并验证

1. 云托管 → 部署服务
2. 拿到访问域名（形如 `https://xxx.tcloudbaseapp.com`）
3. 验证：浏览器打开 `https://你的域名/api/v1/health`，应返回：

```json
{"status":"ok","movies":26,"tags":64,...}
```

首次启动会自动建表 + 写入 26 部影片种子数据。

### 第 6 步：小程序接入

1. 微信公众平台 → 小程序 → 「开发」→「开发设置」→「服务器域名」
2. 把云托管域名加到 **request 合法域名**（云托管域名通常已被腾讯云标记为合规，直接添加即可）
3. 前端 Taro 小程序里，把 API 地址指向云托管域名
4. 静默登录：小程序用 `Taro.login()` 拿 code → 调后端 `/api/v1/auth/wx-login`（已实现）

> 更省事的方式：用云托管的「**云调用**」，小程序端免配置 request 域名、免鉴权中间层。

## 四、成本预估

| 项目 | 费用 |
|---|---|
| 小程序企业认证 | 300 元/年 |
| 云托管（按量） | 几十元/月（低流量） |
| 云开发 MySQL | 几十元/月起 |
| 大模型 API | 按量（DeepSeek 很便宜） |

## 五、上线后要改的地方

1. `LLM_API_KEY` 填上后，推荐/解读/笔记回应才是真 AI
2. 分享卡片、观心月历里的《观电影法》书籍原话，替换成你从禅说平台确认的原话
3. 前端小程序（Taro + React）还需单独开发（后端已就绪）
