# 免费内测部署指南（0 元，免备案，免服务器）

> 用「Render 免费档 + 免费 Postgres」把影境档案后端免费跑起来，拿链接发给内测用户。

## 一、方案

| 组件 | 用谁 | 费用 |
|---|---|---|
| 后端容器 | Render（Web Service，免费档） | 免费 |
| 数据库 | Neon 或 Supabase（免费 Postgres） | 免费 |
| 前端 | 现有 `static/` H5（随后端一起部署） | 免费 |

结果：得到一个 `https://xxx.onrender.com` 链接，直接发人内测。

## 二、第 1 步：准备免费 Postgres（Neon 为例）

1. 打开 [Neon](https://neon.tech) 注册（GitHub 登录即可）
2. 新建一个项目 → 自动生成一个数据库
3. 复制「连接串」，形如：
   ```
   postgresql://用户名:密码@xxx.ap-southeast-1.aws.neon.tech/库名?sslmode=require
   ```

## 三、第 2 步：部署到 Render（一键蓝图）

仓库根目录已放好 `render.yaml`，可以**一键部署**：

1. 把 `cinelib` 整个目录推到 GitHub
2. Render 控制台 → 「New → Blueprint」→ 选中你的仓库
3. Render 会自动读取 `render.yaml`，创建服务
4. 在创建时手动填 3 个值：`CINELIB_DATABASE_URL`、`LLM_API_KEY`（其余自动生成）

> 若不用蓝图，也可手动：New → Web Service → Root Directory 填 `backend`，Build 命令 `pip install -r requirements.txt`，Start 命令 `uvicorn app.main:app --host 0.0.0.0 --port $PORT`。

## 三、免费大模型 Key（让 AI 解读/笔记回应真正跑起来）

**推荐：智谱 GLM-4-Flash（完全免费）**

1. 打开 [智谱开放平台](https://open.bigmodel.cn) 注册
2. 控制台 → 「API Keys」→ 创建 Key
3. 环境变量这样填（已在 `render.yaml` 里预设了 base_url 和 model）：

```dotenv
LLM_API_KEY=你的智谱key
LLM_BASE_URL=https://open.bigmodel.cn/api/paas/v4
LLM_MODEL=glm-4-flash
```

> 备选：硅基流动（SiliconFlow）注册送额度，也有免费模型，`LLM_BASE_URL=https://api.siliconflow.cn/v1`。
> 嵌入模型（Embedding）可以不配，系统会用离线哈希，推荐效果已经够好。

## 四、第 3 步：环境变量

```dotenv
# 数据库（把 Neon 连接串改写成 SQLAlchemy 格式，末尾加 ?sslmode=require）
CINELIB_DATABASE_URL=postgresql+psycopg2://用户名:密码@host:5432/库名?sslmode=require

# 大模型（可选，填了推荐/解读才是真 AI）
LLM_API_KEY=你的key
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat

# JWT
JWT_SECRET=换成随机长字符串
```

> ⚠️ 注意：Neon 的连接串开头是 `postgresql://`，要手动改成 `postgresql+psycopg2://`（SQLAlchemy 驱动标识），并把 `sslmode=require` 带上。

## 五、第 4 步：验证

部署完成后，打开：

```
https://你的服务名.onrender.com/api/v1/health
```

返回 `{"status":"ok","movies":26,...}` 即成功。首页就是 `https://你的服务名.onrender.com/`。

## 六、免费档的注意事项（如实告知）

1. **休眠**：闲置约 15 分钟会休眠，下次访问要等几十秒冷启动
2. **国内访问速度**：一般，能打开但不快（内测够用）
3. **SQLite 换成了 Postgres**：数据持久化，不怕重启丢数据
4. 免费额度有限，但**内测（几十人）完全够用**

## 七、不想配 Postgres，最快临时方案

如果只想**临时**发几个人测一下、不在乎数据，可以完全用 Render 免费档跑 **SQLite**（数据存在容器里，重新部署会丢）：

- 不配 `CINELIB_DATABASE_URL` 即可（默认 SQLite）
- 其余步骤同上，最省事
