# 微信外链合规要点（公众号嵌入 H5 必读）

> 微信近年持续收紧公众号外链，违规会被**封禁链接、限制功能、甚至封号**。本要点基于微信官方规范整理，供「影境档案」嵌入公众号时对照执行。

## 一、核心红线（触碰即封）

1. **只能跳「业务域名」**：公众号菜单/文章里能跳的网页，必须是你已在「公众号后台 → 设置与开发 → 公众号设置 → 业务域名」里**配置并完成校验**的域名。没配的域名，链接点了直接打不开或被拦截。
2. **不得诱导分享/关注**：网页里不能出现「转发到 3 个群才能看」「关注公众号才能解锁」这类诱导文案。
3. **不得违规导流私域**：外链不能把用户引到个人微信、微信群二维码、其他 App 下载等（见[《关于公众号内容导流行为的规范》](https://m.thepaper.cn/newsDetail_forward_29272161)）。
4. **内容合规**：网页内容不得涉黄赌毒、夸大宣传、医疗断言等（见[《微信外部链接内容管理规范》](https://weixin.qq.com/agreement/weixin_external_links_content_management_specification)）。

## 二、正确姿势（合规做法）

| 环节 | 正确做法 |
| --- | --- |
| 域名 | 用**已 ICP 备案**的自有域名，配 HTTPS，加到「业务域名」+「网页授权域名」 |
| 菜单入口 | 公众号自定义菜单 →「跳转网页」→ 填业务域名下的 URL（不能是第三方短链/未配置域名） |
| 登录 | 用**网页授权 snsapi_base**（静默，无需用户确认），不要诱导授权 |
| 分享 | 页面内可用微信 JS-SDK 做「分享给好友/朋友圈」按钮（合规），但**不能设置「必须分享才能看」** |
| 跳转 | 站内跳转走同域名内页面；**不要**跳转到未备案/未配置的外部域名 |
| 活动 | 观影活动信息放页面内静态展示即可，报名可用「阅读原文」跳公众号文章，或引导到合规的群二维码（需谨慎） |

## 三、对「影境档案」的具体落地建议

1. **唯一域名原则**：所有 H5 资源（首页、详情、分享图）都放在**同一个业务域名**下，避免跨域跳转。
2. **分享卡片**：用公众号 JS-SDK 的 `updateAppMessageShareData` / `updateTimelineShareData` 自定义分享标题+图（比纯 og 标签在微信里更稳）。
3. **登录静默化**：已内置 `snsapi_base` 静默登录，无需用户点确认，符合「不打扰」原则。
4. **避免诱导词**：文案中不出现「转发」「集赞」「关注解锁」等词。
5. **活动区合规**：活动报名引导到**公众号文章/小程序**，不要直接放个人微信二维码（有导流风险）。
6. **备案前置**：域名 ICP 备案是硬门槛，未备案域名无法配置业务域名。

## 四、审核前自查清单

- [ ] 域名已 ICP 备案 + HTTPS
- [ ] 已加入「业务域名」并通过校验文件验证
- [ ] 已加入「网页授权域名」（如需 OAuth 登录）
- [ ] 页面无「转发/关注/集赞才能看」类诱导
- [ ] 页面无个人微信/群二维码导流
- [ ] 内容不含夸大、医疗断言、敏感表述
- [ ] 分享按钮走 JS-SDK，非诱导

---

*依据：微信官方《微信外部链接内容管理规范》《关于公众号内容导流行为的规范》及 2024–2025 公众号外链规范解读。政策可能更新，上线前请以微信公众平台最新公告为准。*
